# Restricted Data Notice

This public reproducibility repository follows a processed-only release policy.

The raw wastewater-treatment source datasets are not redistributed.

Excluded source datasets:

- `Seoul_Tancheon_1.csv`
- `Ulsan_Yongsan.csv`

The Ulsan WWTP dataset is subject to third-party data-sharing restrictions and
cannot be publicly redistributed.

The Seoul wastewater-treatment source is documented in the associated article,
but the local source copy used in this project is not redistributed here.

Raw-data directories are excluded from the public repository.

The public release instead provides permitted nonrestricted materials such as:

- source code;
- preprocessing and modeling workflows;
- blocked cross-validation definitions;
- processed feature artifacts;
- fold-level predictions;
- model metrics;
- alarm-budget outputs;
- figure-source data;
- table-source data;
- reproducibility and audit artifacts.

Associated publication:

**Operationalizing Nitrogen Compliance: A Leakage-Safe, Alarm-Budget Framework for Wastewater Treatment Early Warning**

ACS ES&T Water (2026)

https://doi.org/10.1021/acsestwater.6c00549
