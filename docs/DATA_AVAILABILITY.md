# Data Availability

The public repository does not redistribute the raw wastewater-treatment
source datasets used in the study.

Excluded local source files:

- `Seoul_Tancheon_1.csv`
- `Ulsan_Yongsan.csv`

The Ulsan wastewater-treatment dataset is subject to third-party data-sharing
restrictions.

The Seoul wastewater-treatment source is documented in the associated
publication; the local copy used for the analysis is not redistributed here.

Meteorological observations used in the study were obtained from the Korea
Meteorological Administration Open MET Data Portal.

The repository provides permitted nonrestricted computational materials,
including code, permitted derived analysis artifacts, validation definitions, fold-level
predictions, model metrics, alarm-policy outputs, and figure/table source data.

For additional details, see:

- `data/RESTRICTED_DATA_NOTICE.md`
- `LICENSE-DATA.md`

Associated article:

https://doi.org/10.1021/acsestwater.6c00549
