# Feature Lineage Audit

## Scope
- Models covered: Persistence, Ridge, ElasticNet, HGBR, BCR-TCN (H5 context row).
- Horizons covered: H1, H3, H5.
- This is design-only lineage and feasibility auditing; no training/tuning/prediction was executed.

## Core Construction Rules
- TNout_lagk(t) = TNout(t-k).
- TNout_rollw(t) = mean(TNout(t-w), ..., TNout(t-1)); day t is excluded.
- Non-TN rolling predictors in ordinary/v2 builders use rolling windows anchored at day t (include day t).

## Key Findings
- H1/H3 ordinary corrected lineage uses TNout_lag1 + TNout_roll7 + TNout_roll14 with 18 features.
- H5 v2 lineage uses expanded TN memory (lags 1/3/5/7 and rolls 7/14/30) with 34 features.
- ulsan_H3_features_v2.npz exists but final corrected H3 models do not consume it.
- Persistence has no adjustable lag-window feature set.
