# Methods and Materials Master File (MAIN plus SI)

This file is the manuscript-ready master source for Methods and Materials, with a strict split into MAIN section content and SI extension content. It follows the implemented pipeline in this repository and keeps all equations aligned to executed code and exported artifacts.

## 1) Full Methods and Materials Narrative (Master)

### 1.1 Problem framing and objective

The study targets daily effluent TNout forecasting under bounded operator attention. Instead of evaluating only global error, the protocol evaluates constrained decision utility at fixed top-k alarm budgets.

### 1.2 Data and target definition

Main dataset: data/raw/Ulsan_Yongsan.csv

External strict SI dataset: data/raw/Seoul_Tancheon_1.csv

For each horizon H in {1,3,5}, target is:

$$
y_t^{(H)} = TNout_{t+H}
$$

### 1.3 Leakage-safe feature principle

Feature vector at time t uses only information up to t:

$$
\mathbf{x}_t = \phi(\mathcal{Z}_{\le t})
$$

Features include lags, rolling windows, process load signals, weather aggregates, interactions, and seasonality terms, generated by src/build_ulsan_npz_v2.py into features/ulsan_H1/H3/H5_features_v2.npz.

### 1.4 Blocked chronology-safe split protocol

Expanding blocked CV with TimeSeriesSplit(n_splits=3):

$$
\max(\mathcal{T}_i) < \min(\mathcal{E}_i),\quad
\mathcal{T}_1 \subset \mathcal{T}_2 \subset \mathcal{T}_3
$$

No shuffling is used.

For deep model training, each outer train block is split chronologically into subtrain and validation (val_frac = 0.15).

### 1.5 Fold-safe normalization

$$
\tilde{\mathbf{x}}_t = \frac{\mathbf{x}_t - \mu_i}{\sigma_i + 10^{-6}},
\quad
\mu_i,\sigma_i \text{ estimated on subtrain only}
$$

### 1.6 Model families and rationale

1. Persistence baseline: operational minimum benchmark.
2. ElasticNet and Ridge: robust low-variance baselines.
3. HGBR with Optuna: nonlinear tabular interactions.
4. BCR-TCN v1.1: causal sequence modeling with threshold-aware ranking loss.
5. Hybrid point and hybrid rank models: separate optimization for point and decision performance.

### 1.7 Optimization and loss equations

Point metrics:

$$
MAE = \frac{1}{n}\sum |y-\hat y|,
\quad
RMSE = \sqrt{\frac{1}{n}\sum (y-\hat y)^2}
$$

$$
MASE(m)=\frac{\frac{1}{n}\sum |y-\hat y|}{\frac{1}{n-m}\sum |y_t-y_{t-m}|+\epsilon}
$$

Alarm-budget protocol:

$$
k = \lceil rn \rceil,
\quad
Precision@k=\frac{TP}{k},
\quad
Recall@k=\frac{TP}{TP+FN}
$$

Random baseline recall:

$$
\mathbb{E}[Recall@k]=r
$$

BCR-TCN objective:

$$
\mathcal{L}_{total}=w_{reg}\mathcal{L}_{Huber}+w_{bce}\mathcal{L}_{BCE}+w_{rank}\mathcal{L}_{pair}
$$

with implemented weights 1.0, 0.6, 1.4.

Pairwise ranking term:

$$
\mathcal{L}_{pair} = \frac{1}{M}\sum_{m=1}^{M}\log\left(1+e^{-(s_m^+-s_m^-)}\right)
$$

Gradient clipping:

$$
\mathbf{g}_{clip}=\mathbf{g}\cdot\min\left(1,\frac{c}{\|\mathbf{g}\|_2+\epsilon}\right),\quad c=1.0
$$

### 1.8 Hybrid rank fusion and guarding

Rank-fusion score at threshold tau:

$$
S_\tau(t)=w_{tcn}R(p_\tau^{tcn}(t)) + \sum_m w_m R(\hat y_m(t)),
\quad
\sum_j w_j=1,\ w_j\ge 0
$$

Guarded optimization constraint:

$$
Precision_{candidate}(\tau,r) \ge Precision_{paper-fixed}(\tau,r)
$$

Guarded policy function:

$$
S_\tau^{guarded}(t;r)=
\begin{cases}
S_\tau^{paper-fixed}(t), & r \le r_{guard} \\
S_\tau^{policy}(t;r), & r > r_{guard}
\end{cases}
$$

with r_guard = 0.05 in final guarded run.

### 1.9 Strict held-out testing and external stress test

1. Outer blocked test folds are strictly unseen during tuning.
2. External Seoul dataset is used as strict SI hold-out verification without retuning for claim inflation.

2. Guarded constraints to protect conservative operations.
3. Policy-specific operating-point optimization rather than one global winner.
4. Diagnostic transparency as part of method validity, not only SI decoration.
